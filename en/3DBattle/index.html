Little Adventurer VS Robots – 3D Action Game on Unity

Development Duration: 1 week

A 3D Action game containing levels and decent mechanics.



Link to game:
GitHub Repository

Key Features

Action System

Includes attck combos, dash, and others.

Environment & Interaction

Enemy spawn system strongly related with the environment.

Doors and gold coins unlocked by the game progress.

UI System

Simple InGame UI with health and currency.

Pause Menu with basic functionalities.

Character & Combat System

Full animation-based combat with state machines.

Multiple states: Idle, Move, Hurt, Attack, Dead and so on.

2 Different type of enemies with different behaviors and drops.
